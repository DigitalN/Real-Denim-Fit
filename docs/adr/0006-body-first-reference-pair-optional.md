# Body measurements always, a reference pair optional

Every user gives body measurements and a desired fit, and a reference pair is optional. At each measuring point, matches aim at a target. Where the user has a reference pair with a reading at that point, the target is that reading shifted by how the pair feels. Everywhere else it's the body plus the ease the desired fit calls for. The body also sets a hard lower limit: anything tighter than the body plus minimum ease is left out, even when it's close to the reference pair.

## Considered Options

- **A reference pair alone.** Comparing garment to garment is the most reliable, but people without a pair they know would be stuck, and a pair can't tell you that a cut won't get over your thighs.
- **The body alone.** Everyone can do it, but the ease it uses is a typical figure, not the user's own. That's why a reference pair takes over wherever it has a reading.
