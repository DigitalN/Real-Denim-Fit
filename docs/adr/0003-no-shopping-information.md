# No shopping information

The app says which jeans to look into, never where to buy them: no shop links, stock, sale prices or stockists. Prices are the brand's own list price, and "I can try this brand on locally" is something users mark themselves. Shop information goes stale and wrong faster than anything else, and one wrong "in stock at…" would make people doubt the fit advice too. This is written down so nobody adds buy links to be helpful.
